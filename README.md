# 🎮 DUEL ARENA — Rock Paper Scissors

A simple and interactive **Rock Paper Scissors** web game where you compete against the computer. Choose your move, let the computer make its choice, and see who wins!

## 📌 About the Project

**DUEL ARENA** is a browser-based Rock Paper Scissors game designed with a clean and interactive interface.

The player can:

* ✊ Choose **Rock**
* ✋ Choose **Paper**
* ✌️ Choose **Scissors**
* 🤖 Play against the computer
* 🏆 Track the score
* 🔄 Reset the match
* 🎮 Continue playing in **endless mode**

## ✨ Features

* 🎮 Interactive Rock Paper Scissors gameplay
* 🤖 Random computer moves
* 🏆 Player vs Computer scoring
* 🔄 Reset Match functionality
* ♾️ Endless gameplay
* 📱 Simple and user-friendly interface
* ⚡ Runs directly in a web browser
* 🎨 Clean gaming-style interface

## 🕹️ How to Play

1. Open the **DUEL ARENA** game.
2. Choose one of the three moves:

   * Rock
   * Paper
   * Scissors
3. The computer automatically selects its move.
4. The winner is determined using the standard rules:

   * **Rock beats Scissors**
   * **Scissors beats Paper**
   * **Paper beats Rock**
5. The score is updated after each round.
6. Continue playing or click **RESET MATCH** to start again.

## 🧠 Game Logic

The game follows the classic Rock Paper Scissors rules:

| Player    | Computer  | Result          |
| --------- | --------- | --------------- |
| Rock      | Scissors  | 🏆 Player Wins  |
| Paper     | Rock      | 🏆 Player Wins  |
| Scissors  | Paper     | 🏆 Player Wins  |
| Rock      | Paper     | ❌ Computer Wins |
| Paper     | Scissors  | ❌ Computer Wins |
| Scissors  | Rock      | ❌ Computer Wins |
| Same Move | Same Move | 🤝 Draw         |
